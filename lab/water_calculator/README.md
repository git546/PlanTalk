# PlanTalk 수분 계산 실험실

앱, Supabase, FastAPI를 실행하지 않고 수분 계산 규칙만 반복 시험하는 Windows용 로컬 프로그램입니다.
기본 프로필은 현재 백엔드의 `water-balance-rules-v1`과 같은 결과를 냅니다.

## 실행

프로젝트 최상위 폴더에서 실행합니다.

```powershell
python -m lab.water_calculator.app
```

별도 설치 패키지는 필요하지 않습니다. Python 표준 라이브러리의 Tkinter를 사용합니다.
Windows에서는 `lab/water_calculator/run.cmd`를 더블클릭해도 실행할 수 있습니다.

## 실험 순서

1. 충분히 물을 주고 배수가 끝난 화분의 무게를 `젖은 목표 무게`로 기록합니다.
2. 관찰 시작·종료 무게와 기간 중 누적 급수량·배수량을 입력합니다.
3. 기본값으로 먼저 계산해 기준 결과를 남깁니다.
4. 센서와 실제 급수 결과를 비교하면서 보정 계수를 하나씩 변경합니다.
5. 프로필 이름과 버전을 올리고, 각 실험을 `세션 JSON 저장`으로 기록합니다.

결과 화면은 현재 프로필과 백엔드 v1 기본값의 차이를 함께 표시합니다. 저장한 세션 JSON에도
`baseline_result`와 보정 후 `result`가 함께 들어가므로 나중에 어떤 계수가 결과를 얼마나 바꿨는지
다시 확인할 수 있습니다.

## 보정 계수

- `물 밀도`: 기본 가정은 물 1mL = 1g입니다.
- `손실 보정 배수`: 계산된 기간 수분 손실량에 곱합니다.
- `손실 보정 편향`: 손실량에 일정한 mL 값을 더하거나 뺍니다.
- `권장 급수 보정 배수`: 목표 무게까지 필요한 급수량에 곱합니다.
- `물주기 기준 마진`: 기존 기준 무게에 g 단위 마진을 더합니다.

한 번에 여러 계수를 바꾸면 원인을 구분하기 어렵습니다. 기본 프로필을 대조군으로 두고 한 계수씩 조정하세요.

## 백엔드 반영 방법

실험 중에는 이 폴더만 수정하고 백엔드 계산기는 그대로 둡니다. 실험 프로필이 안정되면 다음 순서로 반영합니다.

1. 채택할 프로필과 대표 세션 JSON을 확정합니다.
2. `engine.py`의 보정 규칙을 `backend/app/domain/water_balance.py`에 옮깁니다.
3. 계산 버전을 `water-balance-rules-v2`로 올립니다.
4. 저장된 대표 세션을 회귀 테스트로 추가합니다.
5. 기존 v1 결과와 차이를 검토한 뒤 API와 모바일 앱에 연결합니다.
