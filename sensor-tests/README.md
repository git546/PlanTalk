# 아두이노 센서 개별 테스트

아두이노 우노에서 센서를 각각 시험한 스케치입니다. 각 폴더의 `.ino` 파일을 Arduino IDE에서 열어 개별적으로 업로드하고 시리얼 모니터를 9600 baud로 설정합니다. 한 번에 하나의 스케치만 실행되며, 동시에 읽는 통합 코드는 아닙니다.

| 센서 | 신호 연결 | 필요 라이브러리 | 출력 |
| --- | --- | --- | --- |
| DHT11 | S → D2 | Adafruit DHT sensor library 및 의존 라이브러리 | 온도(°C), 습도(%) |
| 조도 저항 | 10kΩ 저항과 분압 회로의 중간 → A0 | 없음 | 상대적인 원본값, lux 아님 |
| 로드셀 + HX711 | DT → D2, SCK → D3 | HX711 Arduino Library (Bogdan Necula) | 보정 전 원본값, g 아님 |
| SEN0193 토양 수분 센서 | 신호 → A0 | 없음 | 원본값, 수분 함량 % 아님 |

각 센서의 전원과 GND를 제품에 맞게 연결하고 배선을 바꿀 때는 USB 전원을 분리합니다. 조도 회로는 조도 저항을 5V와 A0 사이에, 10kΩ 저항을 A0와 GND 사이에 연결합니다. 로드셀은 무게 단위 측정 전 보정이 필요합니다. 토양 센서는 흙과 위치에 따른 비교가 필요하며 전자 부품을 물에 닿게 하지 않습니다.

개별 테스트에서 온습도 출력, 밝기에 따른 변화, 로드셀 하중에 따른 변화, 토양 센서의 값 출력을 확인했습니다. 센서 동시 연결, 로드셀 보정과 실제 급수 판단 기준은 추후 진행합니다.
