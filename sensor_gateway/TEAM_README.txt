PlanTalk 센서 게이트웨이
========================

1. 아두이노에 plantalk_uno.ino 통합 코드를 업로드합니다.
2. Arduino IDE의 시리얼 모니터를 닫습니다.
3. 아두이노를 USB로 연결합니다.
4. PlanTalk-Sensor-Gateway.exe를 실행합니다.
5. 화면 순서대로 연결 확인, 영점 측정, 기준 추 측정을 진행합니다.
6. 수집 시작을 누릅니다.

주의사항
--------
- .env.gateway 파일은 실행 파일과 같은 폴더에 두어야 합니다.
- .env.gateway에는 테스트 계정 정보가 있으므로 GitHub나 공개 채팅에 올리지 않습니다.
- Windows 보안 경고가 표시되면 파일을 전달한 팀원에게 출처를 다시 확인합니다.
- 서명되지 않은 시험용 실행 파일이라 Windows SmartScreen 경고가 표시될 수 있습니다.
- COM 포트를 다른 프로그램이 사용 중이면 연결되지 않습니다.
- 로드셀 보정은 저울을 비운 상태와 무게를 아는 기준 추로 진행합니다.
- 수집 중에는 PC와 아두이노의 USB 연결을 유지합니다.

문제 발생 시 실행 기록의 오류 문구와 아두이노 배선 사진을 함께 공유합니다.
